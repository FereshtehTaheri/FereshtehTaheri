## Featured Research

### Urban Accessibility & Explainable GeoAI

A reproducible research portfolio exploring relationships between spatial opportunity and experienced access to urban services.

The repository includes:

- spatial and social predictors
- geographically structured validation
- machine-learning workflows
- SHAP-based model interpretation
- synthetic, non-sensitive public data examples
- documentation of the analytical workflow
